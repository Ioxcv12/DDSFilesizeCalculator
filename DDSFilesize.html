DDS Filesize Calculations

This calculates the filesize of DDS files with and without mipmaps. This variant is HTML for easier website usage. Doesn't include 128-byte DDS header. BC5/7 support not implemented yet.

These are the important file formats that you will likely use the most in KSP modding.
8192 KB for DXT5/L8/DXT5nm
10384 KB for DXT5/L8/DXT5nm with mipmaps*
4096 KB for DXT1
5461 KB for DXT1 with mipmaps

* L8 file format is used for heightmaps. Mipmaps should not be used on heightmaps.

Warning: It is not recommended to use uncompressed file formats other than L8; they have a huge filesize. Consider DXT1/DXT5 instead.
