Calculates DDS/PNG format filesize. <br>
Now an HTML app! <br>
To use, just download the source code for the HTML app. Should download as a ZIP; simply unpack. Pretty much any device should be capable of extracting ZIP files and this should work on most modern browsers. <br>
However, note that mipmaps are incorrect in the C version and are fixed in HTML <br>
The C version remains in commits if you want to use it, for whatever reason. <br>
